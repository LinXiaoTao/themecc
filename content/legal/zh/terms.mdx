ThemeCC 是 Claude Code 主题的目录。使用本站即表示你同意这些条款。

## 独立项目

ThemeCC 不是 Anthropic 制作、认可或支持的项目。Claude 和 Claude Code 是 Anthropic 的商标。

## 主题归作者所有

每个主题都是其作者的作品,并保持页面上标明的许可证。ThemeCC 为每个条目列出许可证、作者和来源。部分 CLI 主题是对现有配色方案的移植,它们会标明上游项目并保留其版权声明。

预览图片和视频归主题作者所有。

## 不附带担保

主题按现状提供,不附带任何形式的担保。桌面主题是 mod:以与 Claude Code 相同的权限运行、不在沙盒里的代码。维护者会在收录前阅读固定 commit 的源码,但这不能保证主题安全、正确或适合你的用途。安装主题的风险由你自己承担。参见[安装 Claude Code mod 主题安全吗?](/guides/mod-security)。

在法律允许的范围内,ThemeCC 及其维护者不对因使用本站或其中收录的任何主题造成的损失负责。

## 提交

通过 pull request 提交主题,即表示你确认自己是作者或有权提交,你声明的许可证准确,并允许 ThemeCC 收录该条目、展示你的预览素材并链接到你的仓库。你可以随时申请删除。

## 删除请求

如果你是作者、权利人或用户,希望删除某个条目,请在 [ThemeCC 仓库](https://github.com/LinXiaoTao/themecc/issues)提交 issue。收到可信的请求后,相应条目会在核查期间被下架。

## 变更

我们可能修改本站和这些条款。页面顶部的日期是最近一次更新的日期。
