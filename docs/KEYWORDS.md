## 3. 程序化页面门槛

主题详情页由 registry 数据生成。每页必须包含独有内容:预览、颜色令牌、版本要求、权限声明、作者和许可证。缺少预览或描述的条目不生成详情页,不进 sitemap。

上线 2~4 周后,在 GSC 查看详情页的收录和曝光,再决定是否扩大收录数量。

## 4. 上线后调整

用 GSC 效果报告的真实查询词调整 title 和 description,并补充指南页。
